## Texts shipped with each release

Release artifacts include `third-party-licenses/` with the license and notice texts that the packages themselves ship: WPF-UI (MIT, plus its ThirdPartyNotices.txt), CommunityToolkit.Mvvm (MIT, plus ThirdPartyNotices.txt) and the Microsoft.Extensions family (THIRD-PARTY-NOTICES.TXT). The nuspec of every package above declares an SPDX expression (MIT or Apache-2.0); where the package contains no license text file of its own, the standard license text for that SPDX identifier applies and is not reproduced here.

## Items needing manual review before a public release

1. **Apache-2.0 packages (SQLitePCLRaw.\*)**: the packages declare Apache-2.0 but ship no LICENSE or NOTICE file in the nupkg. Before a public release the owner must decide where the Apache-2.0 text and any NOTICE content are taken from (the upstream repository https://github.com/ericsink/SQLitePCL.raw) and add it to `third-party-licenses/`. Not done: nothing was downloaded to check.
2. **SQLite native library**: SQLitePCLRaw.lib.e_sqlite3 contains the native SQLite build (`e_sqlite3.dll` in `runtimes/win-x64/native`). SQLite itself is in the public domain (https://sqlite.org/copyright.html); this is stated by the SQLite project and is not in the nuspec, so it is recorded here as a source claim to be confirmed.
3. **WPF-UI embedded third-party content**: WPF-UI's own ThirdPartyNotices.txt lists VirtualizingWrapPanel (MIT), Fluent UI System Icons, dotnet/wpf, microsoft-ui-xaml and the Segoe Fluent Icons font reference as included in Wpf.Ui. The Segoe Fluent Icons font is a Microsoft Windows font with its own usage terms; whether Winora's use is covered must be confirmed. Winora does not itself ship that font file (the glyphs resolve against the font installed with Windows 11), which is to be verified on the VM matrix.
4. **Microsoft.Extensions.\* and Microsoft.Data.Sqlite**: MIT per nuspec; the packages do not carry a copyright text of their own in the nupkg. Their THIRD-PARTY-NOTICES.TXT is shipped.
5. **xunit.abstractions** (test-only, not shipped) declares only a license URL, no SPDX expression.
6. **GPL compatibility**: MIT and Apache-2.0 dependencies can be combined into a GPL-3.0-only distribution (Apache-2.0 is compatible with GPLv3, not with GPLv2-only). The WiX Toolset SDK (MS-RL, https://licenses.nuget.org/MS-RL) is used only to build the MSI. Its output contains no WiX runtime, custom action or bootstrapper code (tools/verify_dist.ps1 checks that the MSI has no CustomAction table), so the MS-RL copyleft does not attach to Winora artifacts. This is the project's reading, not legal advice; the owner should confirm.
7. Behavior of other tools is reviewed as external evidence only (kept outside this repository) and is not bundled. No assets, descriptions, code or datasets of other tools are included.
