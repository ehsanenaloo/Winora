## Decisions and unresolved limitations

Domain/Application remain platform neutral; hosts share one engine; SQLite commits precede simulation mutation; real Windows changes will not be atomic with SQLite. Worker remains asInvoker and has no pipe/UAC/mutation handlers. Journal schema initialization is versioned/transactional; future versions fail closed. Current journal retains latest operation state rather than an immutable event ledger. Single boolean compare/exchange protects changed current values, but ABA/revision history, multi-step compensation, stale preview binding and complete cross-process orchestration are FND-002. Synchronous database calls can block up to five seconds under contention; production scheduling needs review.

No real registry/service/power/startup/task changes, uninstallers, leftover scan/deletion, hardware measurement or Windows integration adapters were executed or claimed. Uninstall is contracts/policy only. Profile file/UI exchange and real catalog execution are future tasks. Windows 10/edition/ARM64 support, trusted signing/installation/alternate-credential IPC, quarantine UX and measurement protocol remain unresolved. Manual screen-reader/keyboard/high-contrast/DPI checks, supported-OS/hardware VM matrix, privileged security tests, signed packaging and complete redistributable third-party notice extraction are not complete. No universal undo, complete app removal or performance gains are claimed.
